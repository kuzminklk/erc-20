## About

### Description

Website for interacting with Strawberry Vendor smart-contract

### Technologies

Development: Artificial intelligence
Programming language: JavaScript → TypeScript  
Environment: Node.js → pnpm  
Framework: React → Next.js (app router, “/src” directory) → Viem, Wagmi, Connect Kit
Formatting: Prettier, Husky, lint-staged, “.editorconfig”  
Linting: ESLint, TypeScript checks

## Usage

### Visit

You could visit [a deployed website at Vercel](https://strawberry-vendor.vercel.app/)

### Run

1. Install dependencies by `pnpm install`
2. Run development server via `pnpm dev`
